# 🚚 Delivery Operations Analysis

This project analyzes first-mile, transit, and last-mile delivery operations using SQL, Python, and Power BI.
The goal is to identify delivery delays, cost inefficiencies, and partner performance patterns across logistics workflows.

---

## 🛠 Tools Used

- MySQL (Database + SQL Views)
- Python (pandas, numpy, seaborn, matplotlib)
- Power BI (Interactive dashboard)
- GitHub (Version control)

---

## 📁 Project Structure
data → Raw dataset CSV files
sql → Table schemas, views, and sample analytics queries
python → EDA script + cleaned dataset
powerbi → Final Power BI dashboard (.pbix)
images → Screenshots of plots and dashboard

---

## 📊 Key Insights (Python + SQL)

- 75% deliveries completed successfully; remaining failed mostly in the last-mile stage.
- Last-mile duration showed the greatest time variability.
- Cost increases with distance, but partner variations suggest optimization potential.
- Some partners consistently perform faster and cheaper.
